# Исполняемый эталон TL

Источник: AyuGramDesktop `0f2a31bb420de98f331990432265b131b8d836b5`, layer 229.
Оригинальный клон только читается. `codegen_scheme.py` вызывает оригинальный
`lib_tl/tl/generate_tl.py`; CMake компилирует полученную схему вместе с оригинальным
`tl_basic_types.cpp`. В C++ нет своей реализации TL writer. Неиспользуемые функции
`Integration` удаляются linker GC, алгоритмы оригинала не заменяются.

Воспроизведение из корня репозитория (сборка вне оригинального клона):

```bash
nix-shell -p python3 cmake ninja qt6.qtbase microsoft-gsl range-v3 --run \
 'crates/tg-scheme/tests/reference-tools/capture.sh /home/yarik/Projects/AyuGramDesktop /tmp/tl-native'
```

`describe.py` — отдельный небольшой разборщик настоящих api.tl и mtproto.tl.
Он не вызывает tg-tl-gen, не использует его metadata и выдаёт проверяемый JSON.
`emit.py` из одного JSON пишет типизированные вызовы оригинальных C++ factories
и Rust factories. C++ компилятор проверяет их по оригинальной схеме, Rust — по
порту. Имена, типы, условия и порядок полей берутся из JSON, не из Rust parser.
`builders.rs` после генерации форматируется закреплённым rustfmt.

В fixture 2520 определений: 1697 constructors и 823 methods; отдельно встроенный
полиморфный vector (ещё одно определение), 3 образца Vector<int>. Для каждого
остального определения — шесть режимов `(optional present, byte length, vector count)`:
`(false,0,0), (true,253,0), (true,254,2), (true,0,2), (true,3,1), (false,1,1)`.
Flags и flags2 включаются совместно. Во вложенных объектах optional отсутствуют,
векторы пусты, выбирается constructor с минимальной глубиной обязательных полей.
Это ограниченный конечный набор, не перебор всех комбинаций вложений и флагов.
Обёртки с `!X` получают `help.getConfig`. Bare future_salt и boxed типы строятся
типизированными factories. String и bytes заполняются одинаковыми сырыми байтами:
TL допускает их, декодирование UTF-8 этим тестом не проверяется.

Каждая запись binary fixture: u32 LE длина, затем оригинальные байты. Порядок —
JSON definitions, затем режимы 0..5. Формат не хранит имена и текстовый hex,
1 377 396 байт для 15 120 образцов. vectors.bin содержит ещё 3 записи.
Снято на x86_64 little-endian, GCC 15.3, Qt 6.11.2; формат Rust задан явно LE.
Rust проверяет собственную запись, чтение C++ байтов и повторную запись.
Криптографические/производные значения внутри полей здесь произвольны: тест
проверяет TL представление, а не серверную допустимость этих значений.

`manifest.json` хранит SHA-256 входов, fixture и инструментов. При переснятии
надо сравнить JSON и все binary файлы; пустые/частичные fixture не допускаются.
