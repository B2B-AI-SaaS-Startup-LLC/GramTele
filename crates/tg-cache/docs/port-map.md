# lib_storage: карта функций

Источник семантики: AyuGramDesktop `0f2a31bb420de98f331990432265b131b8d836b5`,
lib_storage `ccdc72548a5065b5991b4e06e610d76bc4f6023e`.
Все 24 файла просмотрены целиком вместе с вызовами `Storage::Cache` в SourceFiles.
Имена Rust ниже относительно `crates/tg-cache/src`; тесты — из `tests/*.rs`
или модулей `#[cfg(test)]`. Декларация и её определение считаются одной
функцией; перегрузки выделены отдельно. Лямбды входят в окружающую функцию.
SFINAE/пустые рекурсивные шаблоны заменены закрытым enum Record, без runtime-заглушек.

Итого: **252 строк функций; 252 реализаций; 252 с исполняемыми тестами; 0 отложенных**.

`storage_pch.h` не содержит функций: его роль заменили импорты модулей Rust;
проверка — сборка workspace и тесты ниже. Сценарии исходного
`storage_encrypted_file_tests.cpp` разобраны в [карте тестов](cache-database-map.md).
Это закрывает прежние partial: буферизация QFile, short write/ENOSPC/flush,
перенос всех двухпроцессных секций без sleep. Windows/macOS runtime отдельно
не запускался; это ограничение проверки, а не пропуск метода.
