# Карта данных AyuGram

Оригинал: `0f2a31bb420de98f331990432265b131b8d836b5`. Декларация и её out-of-line
определение считаются одной функцией; inline getters и overloads — отдельно.
Неявные special members не добавлены; четыре явно default/delete special members
AyuSettings заменены владением Rust (без Clone), не исполняемым кодом.

Сохраняемых конечных настроек **115**: 88 корневых (включая shadowBanIds), 14 ghost,
13 message shot. Два контейнерных ключа дают 117 определений JSON-ключей.
Дополнительно читаются 8 старых корневых ghost-ключей для миграции;
ghostModeActive вычисляется, не сохраняется. В PLAN.md указано 124 сохраняемые
настройки; 124 самостоятельных сохраняемых значений в этом оригинале нет.
Все перечисленные 115 изменены и проверены нативным serializer, не только defaults.

## Таблицы и границы

Все восемь таблиц: SchemaVersion, DeletedMessage, EditedMessage, DeletedDialog,
RegexFilter, RegexFilterGlobalExclusion, SpyMessageRead, SpyMessageContentsRead.
SchemaVersion также читается и пишется реальной миграцией, не вспомогательной заглушкой.
`sqlite_sequence` и autoindex — внутренние объекты SQLite, не девятая таблица данных.
Проверки: native_database_schema_and_all_eight_tables_in_both_directions,
native_sync_schema_migrations_preservation_and_loss, native read Rust.

Настоящие Main::Session/HistoryItem/PeerData и QWidget отсутствуют: извлечённые значения
и Effect проверены тестами, подключение к Core — этап 4, к окнам — этап 5.
Единственная функция целиком только по чтению — repaintApp (перебор реальных QWidget).
Вместо неё выдаётся проверенный Effect::Repaint. Непроверенных скрытых заглушек нет.

Заголовки data/ayu_database.h, ayu_state.h, data/messages_storage.h не добавляют
реализаций сверх соответствующих cpp; их декларации учтены в строках определений.
