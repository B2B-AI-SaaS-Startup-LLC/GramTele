## Как переводить файл

1. Прочитай оригинал целиком: заголовок, реализацию и места, где он используется.
2. Переведи его в модуль Rust с тем же путём и именем внутри целевого крейта. Имена типов и функций сохраняются в принятом для Rust регистре.
3. Места с комментарием `// AyuGram` — патчи форка. Они переводятся вместе с файлом, комментарий сохраняется.
4. Перенеси тесты оригинала, если они есть. Добавь свои на поведение, которое легко сломать при переводе: границы, порядок байтов, переполнения, порядок вызовов.

## Чего не делать

- Не улучшай и не переосмысляй код. Странное на вид поведение оригинала обычно закрывает реальный случай. Если уверен, что нашёл ошибку оригинала, перенеси её и запиши в отчёт.
- Не выбирай библиотеки сам: замены для Qt и остальных зависимостей заданы таблицей в PLAN.md. Если таблица не покрывает случай, опиши проблему и варианты в отчёте.
- Не оставляй заглушек, похожих на готовый код. `todo!()` и `unimplemented!()` допустимы только для явно отложенных функций и перечисляются в отчёте.
- Не меняй форматы на диске и в сети: сериализация TL, файлы `tdata`, `ayudata.db`, `ayu_settings.json` совпадают с оригиналом байт в байт. Такие места проверяются тестами на образцах, а не только круговым преобразованием: круговой тест проходит и при одинаковой ошибке в обе стороны.

## Модель кода

- Граф объектов оригинала держится на сырых указателях с единым владельцем. В Rust это хранилища с типизированными идентификаторами, а не `Rc<RefCell<...>>` на каждом объекте.
- Реактивные цепочки `rpl` переводятся на `tg-rpl`. Время жизни подписок — значения, отменяющие подписку при `drop`.
- Интерфейс и ядро живут в главном потоке, как в оригинале. Фоновая работа идёт через `tg-runtime`.
- `unsafe` допустим только в FFI и в графическом слое, с комментарием `SAFETY` у каждого блока.

## Статусы в реестре

`ledger/files.csv` — по строке на каждый файл оригинала.

| Статус | Значение |
|---|---|
| `todo` | Не начат |
| `partial` | Переведён не полностью; отложенное перечислено в `PROGRESS.md` |
| `done` | Переведён полностью и покрыт тестами |
| `replaced` | Роль файла выполняет сторонний крейт; какой и почему — в `PROGRESS.md` |
| `vendored` | Чужой вложенный код, не портируется |

## Проверка

Rust **1.95.0** берётся из nixpkgs, закреплённого в `flake.lock`.
`nix-shell` читает тот же lock, что и `nix develop`; CI устанавливает ту же
версию вместе с rustfmt/clippy. Проверка из корня репозитория одной командой:

```bash
nix develop --command bash -euc 'cargo fmt --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace'
```
